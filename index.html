Открой index.html и впиши данные своего проекта Supabase в самом верху скрипта:

SUPABASE_URL — Project URL
SUPABASE_ANON_KEY — anon public key
(Supabase → Project Settings → API)

И не забудь выполнить supabase-setup.sql в SQL Editor.
